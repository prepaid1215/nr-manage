가정한 계보 구조 (엑셀에서 확인된 체인 + 사용자 확인 사항 기준):
노상수본 └─ 노상수B ├─ 남욱호 (비사업자, 실적 0, 통과 노드) │ └─ 김진숙 ── 김진숙A / 김진숙B │ └─ 나세빈 ── 나세빈A / 나세빈B │ └─ 노철현 ── 노철현A ── 김건 │ └─ 노철현B ── 진은태 └─ 안영숙(철현) (비사업자, 실적 0, 하위 없음 — 가정)

이 구조가 실제와 다르면 아래 표의 ppId(상위 회원) 값을 직접 고쳐서 다시 계산하면 됩니다.

각 회원 실적 입력 (본인매출 · 대실적 · 소실적)

마감대상이름userId상위(ppId)본인(ordPv)대(maxPv)소(minPv)

"마감대상" 체크된 회원만 캐스케이드 목표를 받습니다. 엑셀의 "b작을때"/"A떨어짐"/"B떨어짐"처럼 특정 시나리오만 보고 싶으면 그 지점까지만 체크하세요.

마감 목표

엑셀 1차 기준 "3,000,000 NV" = 대 1,500,000 + 소 1,500,000으로 가정했습니다. 다른 차수 값으로 바꿔서 비교해보세요.
