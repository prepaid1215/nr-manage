# 팀 공유 권한

기본값은 파트너별 완전 비공개다. 같은 계보 또는 같은 팀이라는 이유만으로 데이터가 공개되지 않는다. 팀 소유자가 `viewer → owner → resource` 단위의 공유 허용을 만들었을 때만 RLS가 접근을 허용한다.

## 임영은 팀 예시

| 로그인 | 임영은 | 한수진 | 주영돈 | 이호정 |
|---|---|---|---|---|
| 임영은 | 본인 | 허용 가능 | 허용 가능 | 허용 가능 |
| 한수진 | 차단 | 본인 | 허용 가능 | 차단 |
| 주영돈 | 차단 | 차단 | 본인 | 차단 |
| 이호정 | 차단 | 차단 | 차단 | 본인 |

`commission`, `private_memo`는 팀 권한 화면의 일반 공유 목록에서 제외한다. 특별한 정책 변경 없이 타인에게 공개하지 않는다.
