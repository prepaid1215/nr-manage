### 3.1 고객 등록의 "방문 지점" (`customers.js`, `customer-visit.js`, `RUN_058`)

  처음이고 가져오기에 실패하면 빈 목록이며 직접 입력은 된다. 후보에 없는 이름도 입력할 수 있다(목록 안에서만 고르게 제한하지 않음).

  RUN_058 적용 전에 메모로 저장된 값은 열로 자동 이전되지 않는다(필요하면 일회성 SQL을 따로 만든다).

### 3.4 교육 탭 스크롤 (`education.js`, `theme.css`)
- 교육 탭은 가이드 원본(`education/index.html`)을 iframe으로 넣는다. 고정 높이 때문에 안쪽 스크롤과 바깥 스크롤이 겹쳐 보였다.
- 지금은 `autoSize`가 iframe 높이를 가이드 내용 길이에 맞춰 **바깥 페이지 스크롤 하나만** 쓴다.
  - 원본의 `scrollTo`·`scrollY`·`pageYOffset`을 바깥 페이지 기준으로 바꿔 "맨 위로 이동" 등이 그대로 작동한다. 바깥 페이지가 `scroll-behavior: smooth`라서 즉시 이동은 `behavior:"instant"`로 호출한다.
  - 원본의 `<dialog>`(이미지 확대·편집)는 iframe 화면 가운데에 뜨므로, 열려 있는 동안만 iframe을 화면 높이로 줄이고 그 위치로 올라간다. 닫으면 높이와 스크롤 위치를 되돌린다.
  - 원본의 `.layout{min-height:100vh}`는 iframe 높이가 내용에 맞춰질 때 계속 커지게 만들어서, 주입하는 스타일에서 `min-height:0`으로 덮어쓴다. 원본에 `100vh`를 쓰는 CSS가 늘면 같은 문제가 생긴다.
