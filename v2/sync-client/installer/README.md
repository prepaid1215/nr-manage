# NRC Sync 설치파일

두 가지 실행파일이 있습니다.

- `NRCSync.exe` — **상시 PC용**(사무실 PC 등). 한 번 설치하면 계속 씁니다.
- `NRCSync-Temp.exe` — **임시 연결용**(잠깐 들어온 노트북 등). 설치도, Windows
  자동실행 등록도 안 하고, 켜져 있는 동안만 수집 PC로 참여합니다. 껐을 때
  트레이에서 "연결 끊기"를 누르면 서버에 등록된 정보도 같이 지워집니다.

## 상시 PC 설치 방법 (`NRCSync.exe`)

1. `NRCSync.exe`를 그 PC의 아무 위치(다운로드 폴더, 바탕화면 등)에 복사합니다.
2. 더블클릭으로 실행합니다.
   - 처음 실행하면 자동으로 `%LOCALAPPDATA%\NRCSync`에 스스로를 설치하고,
     Windows 로그인 시 자동 실행되도록 등록한 뒤, 설치된 위치에서 다시 시작됩니다.
   - 이어서 NRC 수집용 브라우저를 자동으로 설치합니다(1~2분 소요, 최초 1회만).
3. 앱(웹)에서 이미 로그인된 상태로 설정 > 수집 PC 탭에서 **"이 PC 자동 등록"**을
   누르면 입력창 없이 바로 등록됩니다(미리 '공유 PC 수집 승인'을 해둔 계정이어야
   합니다). 안 되면 옆의 "수동 등록"으로 예전처럼 직접 입력할 수 있습니다.
4. 처음 복사했던 `NRCSync.exe`(다운로드 폴더 등)는 이제 지워도 됩니다 — 이미
   `%LOCALAPPDATA%\NRCSync`에 복사되어 그쪽이 실제로 사용됩니다.

## 임시 연결 방법 (`NRCSync-Temp.exe`)

1. 앱 설정 > 수집 PC 탭의 "노트북 등을 잠깐만 연결하고 싶다면"에서 내려받습니다.
2. 더블클릭으로 실행 — 설치·자동실행 등록 없이 그 자리에서만 켜집니다.
3. 앱(웹)에서 **"이 PC 자동 등록"**을 누르면 바로 등록됩니다.
4. 다 쓰면 트레이 아이콘 오른쪽 클릭 → **연결 끊기**. 서버에서도 즉시 지워집니다.

## 이후 동작

- Windows에 로그인할 때마다 자동으로 조용히(창 없이) 백그라운드에서 실행됩니다.
- 실행 중에는 작업표시줄 오른쪽 아래 트레이 아이콘에 NRC Sync 아이콘이 뜹니다.
  - 클릭(또는 더블클릭): 설정 화면(`http://127.0.0.1:5050/setup`)이 열립니다.
  - 마우스 오른쪽 클릭 → 종료: 이 PC의 수집 기능을 끕니다.
- 이 PC를 켜두는 동안은 "온라인" 상태로 잡혀서 공유 수집 요청을 처리할 수 있습니다.
- 별도로 실행할 필요가 없습니다. 껐다 켜도 다시 자동으로 시작됩니다.

## 확인/제거

- 실행 중인지 확인: 트레이 아이콘 확인, 또는 작업 관리자에서 `NRCSync.exe` 프로세스 확인
- 오류가 있었다면 로그 파일: `%LOCALAPPDATA%\NRCSync\nrcsync.log`
- 완전히 제거:
  1. 트레이 아이콘 오른쪽 클릭 → 종료 (또는 작업 관리자에서 `NRCSync.exe` 프로세스 종료)
  2. `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\NRCSync.vbs` 삭제 (자동 실행 해제)
  3. `%LOCALAPPDATA%\NRCSync` 폴더 삭제
