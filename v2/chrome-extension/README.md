# 59만모바일 캡처 도구 (크롬 확장)

자동 수집이 어려운 채널(인스타그램 등)에서, 지금 보고 있는 페이지의 제목이나
드래그로 선택한 텍스트(방문자수 등)를 눌러서 클립보드로 복사하는 보조 도구입니다.
복사한 내용은 앱의 활동 탭 "제목 메모"나 NRC Sync의 "오늘 제목 메모장"에 붙여넣으면 됩니다.

크롬 웹스토어에 올리지 않고 "압축해제된 확장 프로그램"으로 개인 설치합니다.

## 설치 방법

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`v2/chrome-extension`)를 선택

설치되면 크롬 툴바에 아이콘이 생깁니다.

## 사용 방법

1. 캡처하고 싶은 페이지(블로그 글, 인스타 게시물 등)를 엽니다.
2. 방문자수 등 특정 텍스트가 필요하면 드래그로 선택합니다.
3. 툴바 아이콘 클릭 → 팝업에 페이지 제목과 선택한 텍스트가 자동으로 채워집니다.
4. "제목 복사" 또는 "선택한 텍스트 복사" 버튼을 눌러 클립보드에 복사합니다.
5. 앱이나 NRC Sync의 제목 메모장에 붙여넣습니다.
